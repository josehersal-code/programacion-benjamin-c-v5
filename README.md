# Programación Benjamín C · Versión 5.4 · Fase 3

## Incluido

- Todo lo de la versión 5.3.
- Planificador de sesiones.
- Crear, editar, duplicar y eliminar sesiones.
- Fecha, sesión A/B, título, objetivo y mesociclo.
- Cinco bloques:
  - calentamiento;
  - parte inicial;
  - parte principal;
  - partido / estrategia;
  - vuelta a la calma.
- Selector visual de ejercicios con:
  - imagen completa;
  - nombre;
  - tipología;
  - dificultad;
  - descripción.
- Apartado específico para porteros.
- Observaciones de sesión.
- Vista previa.
- Impresión A4.
- Historial de sesiones.
- Contador de sesiones en Inicio.
- Las sesiones aparecen también en el calendario mensual.

## Publicación

1. Descomprime el ZIP.
2. Sube todo el contenido al repositorio `programacion-benjamin-c-v5`.
3. Commit:
   `Versión 5.4 planificador de sesiones`
4. Netlify desplegará automáticamente.

No requiere SQL adicional.
